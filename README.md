# Портал звернень громадян

**Варіант 5 — Міська рада**

## Опис проєкту
Вебсистема «Портал звернень громадян» призначена для автоматизації процесів подання, обробки, відстеження та розгляду звернень громадян до органів місцевого самоврядування (міської ради).

## Основні характеристики
- **Тип системи:** Web-додаток (Web)
- **Розробник:** Оліферук Іван
- **Група:** ІПЗ-3/1
- **Статус проєкту:**триває проєктування

## Структура документації проєкту
Уся технічна та організаційна документація розміщена в каталозі `docs/`:
- `docs/requirements/` — аналіз вимог та технічне завдання (ТЗ).
- `docs/sdlc/` — обґрунтування моделі SDLC, фази життєвого циклу, дорожня карта (Roadmap) та DORA-рефлексія.
- `docs/board/` — Sprint Plan та скріншоти Kanban-дошки задач.

## Як переглянути документацію
Усі матеріали проєкту розміщено в папці `docs/`.
